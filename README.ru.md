# @goodandready/dsh-moa

> Плагин **Mixture of Agents (MoA)** для **DeepSeek Harness**, добавляющий слэш-команду `/moa <prompt>`.

---

## Обзор

`dsh-moa` реализует архитектуру **Mixture of Agents** в DeepSeek Harness по образцу передовых ансамблевых систем (Hermes Agent, OpenClaw).

Вместо отправки сложной инженерной или логической задачи одной модели, `dsh-moa` выполняет гибкий многофазный процесс:
1. **Интерактивное уточнение требований (Адаптивный опросник):** При широких или неполных запросах (например, `/moa создай калькулятор`) советники формируют варианты реализации, а судья синтезирует компактный опросник из 2–4 вопросов с вариантами ответов до запуска написания кода.
2. **Модели-кандидаты (Proposers / Advisors) и изолированные воркспейсы:** Несколько независимых моделей параллельно анализируют задачу и генерируют файлы в изолированных песочницах `.moa/candidate-N/`.
3. **Модель-агрегатор (Judge / Synthesizer) и промоция файлов:** Мощная рассуждающая модель сопоставляет решения кандидатов, определяет победителя машинным маркером (`WINNER_CANDIDATE_INDEX: N`), переносит созданные файлы победителя напрямую в корень проекта и удаляет временные директории.
4. **Интеграция с Live Canvas:** При создании веб-файлов (`index.html` и др.) плагин автоматически регистрирует их в сервисе `@goodandready/dsh-live-canvas` и предоставляет ссылки для мгновенного запуска предпросмотра в один клик.
5. **Экономия токенов при выводе в чат:** Большие блоки исходного кода заменяются компактными плашками с описанием файлов, сохраняя контекст чата чистым и лаконичным.
6. **One-Shot восстановление модели:** Команда `/moa` действует строго на один ход. Сразу после завершения ответа сессия автоматически и гарантированно возвращается к исходной рабочей модели.

## Возможности

- **Интеграция слэш-команды (`/moa`):** Автодополнение в поле ввода чата DeepSeek Harness через сервис `inputTriggers`.
- **Живые индикаторы прогресса (Heartbeats):** Отображение статуса в реальном времени (`⏳ [Ns] Идёт обработка...`, отметки о завершении генерации каждой моделью).
- **Дисковая изоляция кандидатов:** Реальное создание файлов на диске и перенос лучшего решения в корень проекта.
- **Интеграция с Live Canvas:** Автоматическое открытие созданных интерфейсов в плагине Live Canvas.
- **Параллельный опрос (Fan-out):** Конкурентное выполнение запросов с graceful degradation.
- **Изолированный контекст советников:** Очистка истории от системных промптов агента и дампов инструментов.
- **Нативная карточка настроек DSH:** Карточка в разделе «Настройки → Плагины → Mixture of Agents», использующая системные токены темы `--dsw-alias-*`.
- **Именованные пресеты:** Поддержка нескольких конфигураций моделей (`default`, `code-review`, `deep-reasoning`).

## Использование

В поле ввода чата DeepSeek Harness:

```text
/moa напиши архитектуру распределённого кэша с защитой от dog-piling
```

Или с указанием конкретного пресета:

```text
/moa deep-reasoning найди скрытые гонки данных в этом алгоритме
```

Создание проекта с реальными файлами:

```text
/moa сделай интерактивный калькулятор на HTML, CSS и JS
```

## Настройки

В разделе **Настройки → Плагины → Mixture of Agents**:

| Параметр | Описание | По умолчанию |
|---|---|---|
| **Основной пресет** | Имя пресета по умолчанию при вызове `/moa <prompt>` | `default` |
| **Модели-кандидаты** | Массив `{ provider, model }`, опрашиваемых параллельно | `deepseek:deepseek-chat`, `openai:gpt-4o` |
| **Ведущая модель (судья)** | Модель-агрегатор, синтезирующая финальный ответ | `anthropic:claude-3-7-sonnet` |
| **Температура кандидатов** | Степень креативности кандидатов | `0.6` |
| **Температура судьи** | Степень точности синтезатора | `0.4` |
| **Максимум токенов** | Лимит длины ответа | `4096` |
