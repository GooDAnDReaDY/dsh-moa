# DESIGN.md — dsh-moa

## Product / Purpose
- Назначение: Плагин для DeepSeek Harness, реализующий архитектуру Mixture of Agents (MoA) через команду /moa <prompt>. Позволяет параллельно генерировать варианты решения задачи несколькими моделями-кандидатами (proposers / reference models), после чего ведущая модель-агрегатор (judge / aggregator) оценивает ответы, отбирает лучшее, устраняет ошибки и синтезирует итоговый результат. После завершения команды агент автоматически возвращается к основной модели текущей сессии.
- Аудитория: Пользователи DeepSeek Harness, решающие сложные инженерные, исследовательские, математические и архитектурные задачи, требующие ансамбля моделей и перекрёстной валидации.
- Статус: Active Development

## User Surfaces
- Web/UI: Выпадающее меню composer при вводе /moa с подсказкой и описанием; отображение индикации MoA-хода в чате; DSH Settings Card в разделе плагинов.
- DSH UI / settings / slots: слот settings.plugin.item ядра DSH, ключ dsh-moa. Сворачиваемая карточка настроек пресетов, советников, агрегатора и параметров генерации.
- API: HTTP endpoints хоста: GET /dsh-moa/status, GET /dsh-moa/presets, PUT /dsh-moa/presets, POST /dsh-moa/run.
- CLI / Slash Commands: Команда /moa <prompt> и /moa [preset] <prompt> в строке ввода DSH.
- Документация: docs/design/DESIGN.md, README.md, README.ru.md.

## Visual Direction
- Атмосфера: Строгий нативный UI ядра DeepSeek Harness, гармонично встроенный в существующий интерфейс без визуального шума.
- Утверждённые референсы и что из них берём: Карточки настроек ядра («Консоль», «Цикл агента», «Поиск в вебе»); слэш-меню ядра DSH.
- Не копировать: Сторонние UI-библиотеки, неродные шрифты, кастомные акцентные цвета.

## Foundations
- Цвета и роли: Исключительно переменные темы DSH (--dsw-alias-border-l2, --dsw-alias-bg-layer-3, --dsw-alias-label-primary, --dsw-alias-label-secondary, --dsw-alias-label-tertiary).
- Типографика: Системный стек шрифтов DSH, заголовок карточки 15px/600, пояснения 13px, поля 13px.
- Сетка, отступы, responsive: Карточка 12px border-radius, шапка padding 14px 16px, поля padding 12px 0.
- Accessibility: aria-expanded для раскрытия карточки, семантические кнопки, клавиатурный фокус, контрастные лейблы полей.

## Components And States
- Компоненты:
  1. MoASettingsCard — карточка настройки плагина в списке настроек плагинов.
  2. PresetEditor — редактор моделей-советников и агрегатора.
  3. SlashTrigger — интеграция /moa в inputTriggers.
- Loading / empty / error / success:
  - loading — состояние инициализации настроек и загрузки списка доступных моделей.
  - ready — активная конфигурация с валидным списком моделей.
  - unavailable — хост недоступен или модуль не инициализирован.
  - error — индикация ошибки при валидации или сохранении.
- Формы, валидация и действия: Валидация наличия хотя бы одного советника и одного агрегатора.

## User Flows
- Критические сценарии:
  1. Пользователь вводит /moa <вопрос> в composer:
     - При вводе / отображается пункт moa в списке слэш-команд.
     - После отправки запускается parallel fan-out на советников.
     - Агрегатор синтезирует результат.
     - Следующее сообщение автоматически выполняется на основной модели сессии.
  2. Пользователь настраивает пресет в «Настройки -> Плагины -> Настройки плагинов -> Mixture of Agents»:
     - Выбор кандидатов из доступных в ctx.llm.
     - Выбор агрегатора.
     - Сохранение настроек без перезапуска сервера.

## Do / Don't
- Do:
  - Использовать нативные переменные DSH --dsw-alias-*.
  - Префикс moa- для всех CSS-классов.
  - Обязательно восстанавливать модель сессии в блоке finally.
  - Стрипать служебные tool-результаты перед отправкой советникам.
- Don't:
  - Не оставлять модель агрегатора активной после выполнения хода /moa.
  - Не заводить отдельный раздел верхнего уровня в сайдбаре.
  - Не передавать советникам системный промпт агента с инструментами.
